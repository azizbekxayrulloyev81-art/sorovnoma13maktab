# 13-Maktab Diagnostika va Kasbga Yo'naltirish Portali

Ushbu portal 13-sonli umumiy o'rta ta'lim maktabining 5–11-sinf o'quvchilari uchun psixologik diagnostika, kasbiy qiziqishlar xaritasi va tahlillarini yuritish uchun yangilangan.

## Metodikalar:
- **5–6-sinflar**: Boshlang'ich qiziqishlar va mayllar diagnostikasi.
- **7–8-sinflar**: Yovaysha metodikasi (Kasbiy mayllar va moyilliklar).
- **9–11-sinflar**: «Qiziqishlar xaritasi» (Klimov / Golomshtok metodikasi, 10 ta kasbiy soha, 50 ta savol).
- **Tashkilotchilik va yetakchilik testi**: 20 ta maxsus savol.

## Ishga tushirish:
```bash
pip install -r requirements.txt
python app.py
```
yoki Windows'da `run.bat` faylini ikki marta bosing.
